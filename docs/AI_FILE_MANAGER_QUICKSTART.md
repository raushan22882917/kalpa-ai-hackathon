# AI File Manager Chat - Quick Start Guide

## Get Started in 30 Seconds

### Step 1: Open the Chat
Click the **💬 Chat icon** in the Activity Bar (left sidebar)

### Step 2: Try Your First Command
Type one of these:
```
"Create a file called index.html"
"Make a folder named components"
"Create a React component called Button"
```

### Step 3: Use @ Mentions
Type `@` to see your files, then:
```
"Update @src/App.tsx to add a header"
```

That's it! You're ready to go. 🚀

---

## 5 Essential Commands

### 1. Create a File
```
"Create a file called styles.css"
```
✅ Creates file with starter code

### 2. Create a Folder
```
"Make a folder named utils"
```
✅ Creates empty folder

### 3. Update a File
```
"Update @src/App.tsx to add dark mode"
```
✅ Modifies existing file

### 4. Delete Something
```
"Delete old-file.txt"
```
✅ Removes file or folder

### 5. Generate a Project
```
"Generate a React project structure"
```
✅ Creates complete project

## @ Mention Cheat Sheet

| Action | Command |
|--------|---------|
| Trigger suggestions | Type `@` |
| Filter files | Type `@src/` or `@App` |
| Select file | Click on suggestion |
| Update file | `"Update @file.tsx to..."` |
| Multiple files | `"Update @file1 and @file2"` |

## Tips for Success

### ✅ Do This
- Use @ for file updates
- Be specific in your requests
- Use quick action buttons
- Check the action results

### ❌ Avoid This
- Vague commands like "update the file"
- Forgetting @ when updating files
- Very long, complex requests
- Updating non-existent files

## Troubleshooting

### Problem: Suggestions not showing
**Solution:** Make sure you typed `@` and have files in your workspace

### Problem: File not found
**Solution:** Use @ autocomplete to ensure correct path

### Problem: Update didn't work
**Solution:** Check that you mentioned the file with @

### Problem: Can't delete folder
**Solution:** Folder must be empty first

## Example Workflow

Here's a complete workflow to create a simple app:

```
1. "Generate a React project structure"
   ✅ Creates folders and base files

2. "Create a React component called Header"
   ✅ Creates Header.tsx with boilerplate

3. "Update @src/App.tsx to import and use Header"
   ✅ Adds Header to App.tsx

4. "Create a file called Header.css"
   ✅ Creates stylesheet

5. "Update @components/Header.tsx to add navigation"
   ✅ Adds nav elements to Header
```

**Result:** Working React app with header in under 2 minutes! 🎉

## Pro Tips

Don't overthink it - just describe what you want:
